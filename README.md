思覺失調症及相關譜系障礙（Schizophrenia Spectrum Disorders）的負性症狀——涵蓋動機缺乏（Avolition）、社交退縮（Asociality）、情感平淡（Blunted Affect）與無快感症（Anhedonia）——長期以來為臨床精神醫療與常規抗精神病藥物反應最有限的核心挑戰。

動物輔助治療（Animal-Assisted Therapy, AAT）透過訓練合格之治療動物（如犬隻、馬匹）與專業醫療團隊（職能治療師、心理師、動輔師）之結構化合作，利用人與動物之間非評判性、即時且溫暖的互動特質，活化個案內在行為動機、調節壓力皮質醇反應，並逐步搭建由淺入深的社交鷹架。本知識庫彙整國內外隨機對照試驗（RCT）與統合分析（Meta-Analysis）文獻，對動物輔助介入在負性症狀上的臨床實證療效、神經生化機制、評估量表與大眾去污名化轉譯進行系統性整理。

## 📚 單篇文獻萃取庫

> 💡 **學術檢索導覽**：每篇文獻均完成高規格結構化萃取。點擊各篇 Markdown 標題鏈結，可直接進入閱讀完整的研究參數、統計檢定數據、方法學偏誤評估、跨文獻矛盾比對與大眾生活轉譯。

- 📄 [2026-peraile-huerta-aat-psychosis-meta.md](wiki/sources/2026-peraile-huerta-aat-psychosis-meta.md)：
  - **文獻地位**：最新 PRISMA 系統性回顧與統合分析（*Complementary Therapies in Medicine*，納入 12 篇研究、408 位個案）。
  - **研究設計與樣本**：10 項 RCT + 1 項準實驗 + 1 項前後測（介入組 n = 171 vs 對照組）。
  - **核心實證標竿**：確立 AAT 對思覺失調負性症狀改善具備顯著中等效應值（SMD = -0.51, 95% CI: [-0.95, -0.07], p < 0.05）。敏感度分析顯示排除馬匹後犬類效果穩健；正性症狀與一般病理則無組間顯著差異。
  - **方法學偏誤分析**：多數研究因動物介入實體性無法實施操作者盲法（RoB2 評為有疑慮）；對照組性質（純 TAU vs 積極桌遊活動）對療效判讀具決定性影響。
  - **臨床生活轉譯**：證實動物介入能實質突破傳統藥物難以改善的「退縮與冷漠」，為行為啟動注入動機。

- 📄 [2025-ozturk-equine-aat-rct.md](wiki/sources/2025-ozturk-equine-aat-rct.md)：
  - **文獻地位**：土耳其 2025 年最新馬術 RCT（*Perspectives in Psychiatric Care*，n = 61）。
  - **介入參數**：哈芙林格馬、每週 2 次、每次 40 分鐘、共 8 週、專業馬術治療師與精神科團隊。
  - **核心實證標竿**：揭示馬匹介入大幅消融孤獨感（d = 0.99, p < 0.001）與提升生活品質（d = 1.93, p < 0.001）；PANSS 負性次量表組間無顯著差異（p = 0.610）。
  - **跨研究機轉解析**：犬類強在近身撫摸與負性症狀動機破冰，馬匹則透過全身律動與大視野翻轉自尊與消融深層孤獨。

- 📄 [2023-tyssedal-dog-assisted-review.md](wiki/sources/2023-tyssedal-dog-assisted-review.md)：
  - **文獻地位**：挪威專注於犬類輔助介入（DAI）之系統性回顧（*Nordic Journal of Psychiatry*，納入 11 項研究）。
  - **實證標竿**：以 Cochrane RoB2 與 GRADE 系統性梳理各研究偏誤風險，指出對照組為純常規治療（TAU）時負性症狀改善顯著，但若對照組為等時數積極活動時動物特異效應常被沖淡。

- 📄 [2021-chen-dog-aat-taiwan-rct.md](wiki/sources/2021-chen-dog-aat-taiwan-rct.md)：
  - **文獻地位**：台灣高雄長庚與台大職能治療團隊 RCT（*Psychiatry Research*，n = 40）。
  - **介入參數**：認證治療犬、每週 1 次、每次 60 分鐘、共 12 週、職能治療師主導。
  - **核心實證標竿**：負性症狀達成大效應值改善（SRD = 0.50, p < 0.001）、達成 0% 脫落率（常規組脫落 15%）。建立感官接觸、指令練習、日常任務與社會泛化之四階復健架構。

- 📄 [2019-hawkins-aat-schizophrenia-review.md](wiki/sources/2019-hawkins-aat-schizophrenia-review.md)：
  - **文獻地位**：英國愛丁堡大學早期系統性回顧（*BMC Psychiatry*，納入 7 項 RCT）。
  - **實證標竿**：建立跨物種歷史基線，率先呼籲遵循 IAHAIO 與 One Welfare 動物福祉標準，強調療癒過程中對治療動物的保護。

- 📄 [2016-calvo-dog-aat-rehab-rct.md](wiki/sources/2016-calvo-dog-aat-rehab-rct.md)：
  - **文獻地位**：西班牙 6 個月長週期 RCT（*Frontiers in Psychology*，n = 24）。
  - **核心實證標竿**：證實接觸犬隻 1 小時後唾液皮質醇（壓力荷爾蒙）顯著下降（p < 0.05），復健出席率達 92.9%（常規對照組僅 61.2%）。提供抗壓力平撫的客觀生化佐證。

## 🧠 核心實體與概念網絡

> 💡 **概念專頁導覽**：點擊各核心概念可查閱完整病理機制、量表維度與神經生化假說。

### 負性症狀細項 (Negative Symptoms)：
- 🧠 [avolition.md](wiki/concepts/symptoms/avolition.md)（動機缺乏）：解讀行為「引擎熄火」本質，動物作為外接啟動馬達。
- 👥 [asociality.md](wiki/concepts/symptoms/asociality.md)（社交退縮）：解析治療犬如何作為無威脅的第三者話題，搭起人際溝通橋樑。
- 🎭 [blunted-affect.md](wiki/concepts/symptoms/blunted-affect.md)（情感平淡）：探討內在感受未死、外在表達受阻，藉由觸摸重啟表情肌肉。
- 🌸 [anhedonia.md](wiki/concepts/symptoms/anhedonia.md)（無快感症）：納入 5 週快感感受力顯著回升實證，剖析多感官愉悅刺激。

### 介入模式與媒介 (Interventions)：
- 🐕 [canine-aat.md](wiki/concepts/interventions/canine-aat.md)（犬類輔助治療）：負性症狀改善主力，涵蓋台灣四合一職能介入方案與標準團隊流程。
- 🐎 [equine-aat.md](wiki/concepts/interventions/equine-aat.md)（馬術與馬匹輔助治療）：全身律動、視野提升、尊嚴重建與孤獨感消融核心。

### 評估量表與指標 (Outcome Measures)：
- 📊 [panss-negative.md](wiki/concepts/measures/panss-negative.md)：拆解 7 項評估向度，將抽象的「下降 3 分」具體化為日常生活中的抬頭、微笑與開口。

### 神經與心理機轉 (Mechanisms)：
- 🧬 [oxytocin.md](wiki/concepts/mechanisms/oxytocin.md)（催產素神經迴路）：人犬注視循環與哺乳動物生物級「安全信任感」。
- 🩸 [cortisol-hpa.md](wiki/concepts/mechanisms/cortisol-hpa.md)（皮質醇壓力調節）：解除中樞長年防空警報的客觀生化佐證。
- 🪜 [social-scaffolding.md](wiki/concepts/mechanisms/social-scaffolding.md)（社交鷹架理論）：四階漸進式職能復健架構（感官 → 指令 → 任務 → 社交泛化）。
